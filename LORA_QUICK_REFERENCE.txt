⚙️  COMMON FLAGS
Training:
  --model_name MODEL           Model to finetune
  --dataset_name DATASET       folio or proofwriter
  --output_dir DIR             Where to save model
  --num_epochs N               Training epochs (default: 3)
  --batch_size N               Batch size (default: 4)
  --learning_rate LR           Learning rate (default: 2e-4)
  --lora_r RANK                LoRA rank (default: 16)
  --use_4bit                   4-bit quantization (default)

Evaluation:
  --base_model MODEL           Base model name
  --lora_model PATH            LoRA weights path
  --dataset_name DATASET       FOLIO, ProofWriter, etc.
  --split SPLIT                dev, test, train
  --mode MODE                  CoT or Direct
  --trained_model              Use simple prompt format
  --temperature T              Sampling temp (0 = greedy)

🎯 QUICK START WORKFLOW
1. Train:     python lora_finetune.py --model_name Qwen/Qwen2-7B --dataset_name folio
2. Evaluate:  python lora_evaluation.py --base_model Qwen/Qwen2-7B --lora_model ./lora_output/final_model --dataset_name FOLIO --mode CoT --trained_model
3. Test:      python lora_inference.py --base_model Qwen/Qwen2-7B --lora_model ./lora_output/final_model --mode interactive

💾 MEMORY REQUIREMENTS (4-bit quantization)
├── 7B models:  6-8 GB VRAM
├── 8B models:  7-9 GB VRAM
└── 13B models: 10-12 GB VRAM

If OOM: --batch_size 1 --gradient_accumulation_steps 16

🐛 TROUBLESHOOTING
├── CUDA OOM         → Reduce batch size, increase gradient accumulation
├── Can't access     → huggingface-cli login, request model access
├── Low accuracy     → Use --trained_model flag, check data format
└── Slow evaluation  → Use Direct mode, reduce max_new_tokens
